# 제미나이 프롬프트 모음

> 그대로 복사해서 제미나이에 붙여 넣으면 된다. 아이템 문서(03)에서 자동으로 조립했다.

## 사용 방법

1. 프롬프트 하나를 통째로 복사해서 제미나이에 붙여 넣는다.
2. 결과가 9칸이 아니거나 스타일이 어긋나면 **같은 프롬프트로 다시 생성**한다.
3. 마음에 드는 결과를 파일명대로 저장해서 `game/assets/raw/`에 올린다.
4. 시트 01~07(★)부터 만든다.
