## 0. 이미지 제작 규칙 (모든 아이콘 공통)

### 왜 규칙이 필요한가
AI로 한 장씩 만들면 아이콘마다 각도, 색감, 픽셀 크기가 달라져서 "AI로 딸깍한 느낌"이 바로 난다. 아래 세 가지를 지키면 한 사람이 그린 것처럼 통일된다.

1. **한 번에 9개씩 시트로 만든다.** 같은 이미지 안에서 만들어야 스타일이 맞는다.
2. **배경은 순수한 마젠타(#FF00FF).** 투명 배경은 AI가 잘 못 만든다. 마젠타는 아이템에 거의 안 쓰이는 색이라 내가 스크립트로 깔끔하게 지운다.
3. **글자를 넣지 않는다.** AI가 만든 한글은 깨진다. 상표처럼 보이는 글자도 문제가 된다. 라벨은 색과 모양으로만 표현한다.

> 시트를 올려 주면 내가 **자동으로 잘라서 → 배경을 지우고 → 32×32 픽셀 격자에 맞추고 → 팔레트를 통일**한다. AI 픽셀아트는 진짜 격자가 아니어서 이 후처리가 퀄리티를 좌우한다.

### 마스터 프롬프트 (시트용, 복사해서 쓰기)

```
Pixel art item icon sheet for a Korean post-apocalyptic survival game.
A 3x3 grid of 9 separate item icons, evenly spaced, each icon centered in its own square cell.
Style: 32x32 pixel art upscaled with hard nearest-neighbor edges, no anti-aliasing, no blur.
Limited muted palette: concrete grays, desaturated olive green, dusty navy, warm beige,
with rust orange (#D9772B) and civil-defense yellow (#E3B341) as the only bright accents.
View: slight 3/4 top-down angle, same angle and same scale for every icon.
Lighting: soft light from the top-left, one darker shade on the bottom-right of each object.
Every object has a 1-pixel dark outline (#1A1A1E).
Background: solid flat pure magenta (#FF00FF) everywhere, no gradient, no floor, no shadow on the background, no grid lines.
No text, no letters, no numbers, no logos, no brand names anywhere.
Items, left to right, top to bottom:
1. ...
2. ...
(9개)
```

### 단품용 (시트 결과가 마음에 안 드는 아이템만 다시 만들 때)

```
Single pixel art item icon, 32x32 pixel grid upscaled with hard nearest-neighbor edges,
same style as before: muted palette, rust orange and civil-defense yellow accents,
3/4 top-down view, 1-pixel dark outline, soft top-left light,
solid pure magenta (#FF00FF) background, no text, no logos.
Item: ...
```

### 파일 이름과 올리는 곳
- 시트: `sheet_01.png`, `sheet_02.png` … (아래 시트 번호 그대로)
- 단품: 아이템 ID 그대로. 예: `kimbap.png`
- 올리는 곳: 레포의 `game/assets/raw/` 폴더 (GitHub 웹에서 Add file → Upload files)

### 주의
- **바나나우유의 단지 모양 병은 입체상표로 등록되어 있다.** 일반 우유팩 모양으로 만든다.
- 휴대용 버너, 초코파이처럼 특정 제품이 떠오르는 물건은 **실루엣만 비슷하게, 로고와 색 조합은 다르게** 만든다.
