# 위장 오프닝 · 뉴스 컷신 · 더빙 대본 v0.1

> **목표:** 플레이어는 처음 20분 동안 이게 전쟁 게임인 줄 모른다.
> 편의점 야간 알바 게임인 줄 알고 시작했다가, 새벽 4시 12분에 모든 것이 뒤집힌다.

## 1. 위장 오프닝 구조

| 단계 | 플레이어가 보는 것 | 실제 의도 |
|---|---|---|
| **타이틀** | 「오늘25 야간 근무」. 귀여운 픽셀 편의점, 잔잔한 음악. 부제: *"오늘도 무사히, 아침 8시까지."* | 장르를 숨긴다 |
| **근무 (약 15분)** | 편의점 미니게임: 진열 정리, 폐기 체크, 손님 응대, 라디오 사연 | 일상의 리듬을 몸에 익힌다. 이게 나중에 사라질 것들이다 |
| **복선** | 손님들의 대화와 라디오 속 작은 이상 신호 (아래 3절) | 두 번째 플레이 때 소름 돋게 |
| **04:08** | 라디오 DJ가 노래를 끊는다. "잠시 방송을 중단하고…" | 일상에 금이 간다 |
| **04:09** | 휴대폰으로 뉴스 속보 생방송 → **픽셀 뉴스 컷신 + 더빙** | 상황 설명을 글 대신 뉴스로 |
| **04:12** | 재난문자, 사이렌, 문 사장의 전화 | |
| **04:17** | 섬광 연출 (아래 4절) | |
| **반전** | 하얀 화면 위로 진짜 제목 **「서울 끝」**이 떠오른다. 브라우저 탭 이름도 이 순간 바뀐다 | 제목 자체가 반전 장치 |

### 콘텐츠 경고 처리 (중요)
장르를 숨기더라도 **충격적인 내용이 있다는 사실은 알려야 한다.** 구체적인 내용은 말하지 않는다.
> 타이틀 하단: *"이 게임에는 일부 플레이어가 불편할 수 있는 장면이 포함되어 있습니다."*

(같은 방식의 위장 게임들도 이렇게 처리한다.)

## 2. 근무 파트 미니게임 (재미 요소)

| 미니게임 | 방법 | 이야기 역할 |
|---|---|---|
| **진열 정리** | 진열대 빈칸에 물건 끌어다 놓기. 선입선출(오래된 것 앞으로) | 나중에 같은 진열대를 *털게* 된다 |

| **손님 응대** | 바코드 찍기, 봉투 필요하세요?, 거스름돈 | 손님 각자에게 사연이 있다 |
| **라디오** | 채널 돌리기. 사연 듣기 | 복선이 숨어 있다 |

## 3. 손님과 복선 (근무 파트)

| 시각 | 손님 | 사는 것 | 대사 (복선) |
|---|---|---|---|
| 01:20 | 술 취한 회사원 | 숙취해소제 | "요즘 뉴스 보면 술이 안 깨. 맨날 미사일 쏜대." (농담처럼) |
| 02:05 | 택배기사 | 커피, 에너지음료 | "오늘 군 차량이 엄청 많던데요. 고속도로에." |
| 02:40 | 고등학생 둘 | 컵라면 | "야 학교 단톡에 전쟁 난다는 거 떴는데 ㅋㅋ" "또 그거?" |

## 4. 섬광 연출 (극적으로)

현재 빌드: 하얀 화면 → 문장 → 굉음.
**바꿀 연출 (탑다운 화면이라서 가능한 것):**

| 순서 | 시간 | 화면 | 소리 |
|---|---|---|---|
| 1 | 0.0초 | 갈매기와 비둘기가 한꺼번에 날아오른다. 개가 짖는다 | 새들 날갯짓 |
| 2 | 0.5초 | 모든 휴대폰 화면이 깜빡인다 | 전자음 지직 |
| 3 | 1.0초 | **동북쪽에서 빛이 오면서 모든 그림자가 남서쪽으로 길게 늘어난다** (차, 나무, 사람, 건물) | 완전한 정적 |
| 4 | 1.5초 | 화면 전체가 하얗게 탄다 | 정적 |
| 5 | 4초 | 하얀 화면 위로 **「서울 끝」** | **이명** (높은 삐— 소리가 서서히 줄어든다) |
| 6 | 9초 | 정전. 모든 창문과 가로등이 꺼진 어둠 | 이명이 사라지고 정적 |
| 7 | 9~25초 | 화면 구석의 시계가 04:17 → 04:21로 째깍째깍 넘어간다. 플레이어는 움직일 수 있다 | 심장 박동 |
| 8 | 25초 | **충격파가 화면을 동북쪽에서 남서쪽으로 가로지르며 지나간다.** 지나가는 순서대로 창문이 깨지고, 차 경보음이 하나씩 켜진다 | 굉음 → 유리 깨지는 소리 → 차 경보음의 연쇄 |

> 핵심은 **"빛과 소리가 따로 온다"**는 사실을 글로 설명하지 않고 *눈으로 보게* 하는 것이다. 충격파가 플레이어 쪽으로 다가오는 몇 초가 이 게임 첫 번째 공포의 정점이 된다.

## 5. 뉴스 컷신 (픽셀 이미지 · 제미나이용)

### 규칙
- **가상의 방송사 「한누리뉴스24」** 를 쓴다. 실제 방송사 로고, 스튜디오, 앵커를 닮게 만들지 않는다.
- 이미지에는 **글자를 넣지 않는다.** 자막, 속보 띠, 시간은 게임에서 코드로 얹는다 (한글이 깨지지 않고, 실제 뉴스 화면으로 오인될 위험도 줄어든다).
- 화면 비율 16:9, 320×180 픽셀아트 느낌.

### 마스터 프롬프트 (컷신용)

```
Pixel art cutscene frame for a Korean survival game, 16:9, 320x180 pixel resolution upscaled
with hard nearest-neighbor edges, no anti-aliasing.
Muted palette with deep navy, concrete gray, and warning red-orange accents. Slight CRT scanline feel.
Fictional TV news broadcast. No real broadcaster, no logos.
Leave the bottom 20 percent of the frame as an empty dark band for subtitles.
No text, no letters, no numbers anywhere in the image.
Scene: ...
```

### 대본 원칙
- 실존 인물(대통령, 장관 등)의 이름이나 직책 발언은 넣지 않는다. "정부는", "군은" 수준으로만.
- "합동참모본부", "국가안전보장회의" 같은 기관명은 실제 보도 형식을 따르되, 발언 내용은 가상이다.
- 앵커의 마지막 말이 끊기는 지점은 **플레이어가 가장 궁금한 순간**에 둔다.

## 7. 더빙 제작 방법

| 방법 | 장점 | 단점 |
|---|---|---|
| **AI 음성 서비스** (예: 클로바더빙, 타입캐스트 등) | 빠르고 앵커 톤을 고르기 쉽다 | **상업적 이용·재배포 조건을 반드시 약관에서 확인**해야 한다 |
| **직접 녹음 / 지인 녹음** | 가장 자연스럽고 권리 문제가 없다 | 녹음 환경이 필요하다 |
| **브라우저 음성 (임시)** | 지금 바로 개발 가능, 무료 | 기기마다 목소리가 다르고 품질이 낮다 |

**추천 순서:** 개발은 브라우저 음성으로 먼저 붙여 두고, 녹음 파일이 준비되면 교체한다.

### 녹음 파일 규격
- 형식: `mp3` (128kbps 정도면 충분)
- 파일명: `vo_dj_01.mp3`, `vo_anchor_01.mp3` … (대본 순서대로)
- 뉴스 화면 효과를 위해 **깨끗한 원본**으로 주면, 라디오·TV 질감(필터, 잡음)은 게임에서 입힌다.
