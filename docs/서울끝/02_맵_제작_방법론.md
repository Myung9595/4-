# 맵 제작 방법론 v0.1

> **목표:** 배곧에 사는 사람이 게임 지도를 보자마자 *"여기 우리 동네잖아"*라고 알아보게 만든다.
> **원칙:** 실제 지형의 골격은 지키고, 거리는 압축하고, 이름은 바꾼다.
> (GTA의 로스산토스, 용과 같이의 카무로초가 쓰는 방식)

---

## 1. 세 가지 규칙

| 규칙 | 내용 | 이유 |
|---|---|---|
| **골격은 그대로** | 해안선 모양, 주요 도로, 랜드마크의 **방향과 상대 위치**는 실제와 같게 | 현지인이 알아보는 건 "어디에 뭐가 있는지"다 |
| **거리는 압축** | 비어 있는 거리는 1/5~1/10로 줄인다. 아파트 단지 수십 개는 **플레이할 수 있는 단지 1~2개 + 배경 실루엣**으로 줄인다 | 실제 거리 그대로면 걷기만 하는 게임이 된다 |
| **이름은 바꾼다** | 지명(배곧, 오이도, 월곶, 송도)은 그대로. 아파트 단지, 마트, 대학, 편의점 이름은 가상으로 | 상표권과 실존 단체 문제 회피 |

---

## 2. 두 층 구조와 각각의 실제감 수준

| 층 | 실제 지도 반영 수준 | 만드는 방법 |
|---|---|---|
| **월드맵** (스마트폰 지도 UI) | **가장 높다.** 실제 지도 비율과 방향을 유지한 일러스트형 지도 | 실측 데이터를 단순화해 그린다 |
| **장소 바깥** (단지, 상가 거리) | 중간. 배치와 동선은 실제를 참고하되 압축 | 실측 골격 위에 손으로 배치 |
| **건물 내부** | 낮다. 특정 건물을 복제하지 않는다 | 실제 건물의 **유형**을 참고해 직접 설계 |

**건물 내부를 복제하지 않는 이유:** 실제 아파트 내부 구조나 지하 시설을 그대로 옮기면 보안과 사생활 문제가 생길 수 있다. 대신 "신도시 아파트는 지하주차장이 동끼리 연결된다", "상가는 1층 편의점, 2층 학원, 3층 병원"처럼 **누구나 아는 유형**을 쓴다. 생활감은 그것으로 충분히 난다.

---

## 3. 제작 과정 (파이프라인)

```
① 실측 데이터 확보   OpenStreetMap에서 배곧 영역의 도로, 해안선, 건물 윤곽을 받는다
        ↓
② 참고 자료 수집     카카오맵·네이버 지도의 위성사진과 로드뷰 (참고용으로만)
        ↓
③ 자동 변환         스크립트로 실측 데이터를 단순화하고 게임 축척으로 압축 → 타일맵 초안
        ↓
④ 손으로 다듬기      Tiled 에디터에서 배치, 동선, 숨을 곳, 시야를 직접 설계
        ↓
⑤ 생활감 입히기      아래 체크리스트의 디테일을 배치
        ↓
⑥ 현지인 검증        배곧 주민 1~2명에게 지도만 보여 주고 "어디인지 알겠는지" 묻는다
```

### 라이선스
- **OpenStreetMap:** 무료로 쓸 수 있다 (ODbL). 게임 크레딧에 **"© OpenStreetMap contributors"**를 표기해야 한다.
- **카카오맵·네이버 지도:** 지도 이미지를 게임에 그대로 쓰면 저작권 침해다. **눈으로 보고 참고만** 한다.

### ⚠️ 현재 작업 환경의 제약
이 클라우드 작업 환경에서는 OpenStreetMap 서버(`overpass-api.de`, `openstreetmap.org`)로의 접속이 네트워크 정책으로 막혀 있다. 해결 방법은 두 가지다.
1. 환경 설정의 네트워크 접근에서 해당 도메인을 허용한다.
2. 브라우저에서 openstreetmap.org에 접속해 배곧 영역을 **내보내기(Export)** 한 `.osm` 파일을 업로드한다.

## 4. 1장 배곧 지도 가안 (방향만 반영)

> ⚠️ **아래 배치는 실측 데이터로 검증하기 전의 가안이다.** 방향 관계만 반영했고, 정확한 위치는 ①단계 이후 수정한다.

```
                    ▲ 북 (바다 · 송도 갯벌 · 람사르 습지)
                    │            송도 국제도시 (바다 건너)
   ┌────────────────┴──────────────────────────────┐
   │ [공사 멈춘 다리] ━━━━━━━━━━━━▶ 송도              │
서 │ [대학 캠퍼스]                                    │
해 │                                                  │
   │ [해안 공원]  [아파트 단지 · 대피소]   [단지 상가 · 편의점] ── [월곶] ── [소래철교] ──▶ 소래포구 → 송도
   │              [학원가]   [생명공원]   [중심상업지구 · 마트]  │
   └──────────────────────────────────────────────┘
      [오이도 포구] (남서쪽)            정왕동 (남쪽, 문 사장의 집)
```

### 1장 장소 목록

| 장소 | 게임 속 이름 (가안) | 실제 참고 대상 | 역할 |
|---|---|---|---|
| 도일의 아파트 | 배곧 해오름마을 ○단지 | 신도시 대단지 아파트 유형 | 집, 지하주차장 대피소 |
| 편의점 | 오늘25 배곧점 | 단지 상가 편의점 | 프롤로그, Q1 |
| 학원 | 해오름 학원 | 배곧 상가의 학원 밀집 | Q2 |
| 대학 캠퍼스 | 국립 서해대학교 배곧캠퍼스 | 서울대 시흥캠퍼스 | Q3, 방사선 측정기 |
| 대형마트 | 해마트 배곧점 | 중심상업지구 대형마트 | Q4, 오 반장 |
| 해안 공원 | (실제 이름 확인 후 결정) | 서쪽 해안 공원 | Q5, 송도 조망 |
| 오이도 포구 | 오이도 (실명) | 오이도 포구와 어시장 | 루트 1 |
| 공사가 멈춘 다리 | 배곧대교 (실명 사용 여부 결정 필요) | 배곧대교 사업 부지 | 루트 2 |
| 월곶 · 소래철교 | 월곶, 소래 (실명) | 월곶포구, 소래철교 | 루트 3 |

## 5. 고증 체크리스트

### ✅ 검색으로 확인한 것
- 배곧은 경기 시흥시 정왕동 일대 서해안변에 조성된 신도시다. "배곧"은 "배움의 터"라는 뜻이다.
- 서울대 시흥캠퍼스가 배곧 안에 있다.
- **배곧대교**는 배곧과 송도를 잇는 약 1.89km 해상 교량으로 추진됐다. 송도 갯벌 람사르 습지를 지난다는 이유로 환경단체가 반발했고, **2022년 중앙행정심판위원회가 제동**을 걸었다. 현재 상태는 확인하지 못했다.
  → 게임 속 **"공사가 멈춘 다리"** 설정이 현실과도 잘 맞는다. 다만 실제로 교각이 서 있는지는 확인이 필요하다.
- 배곧과 월곶을 잇는 **보행교**가 추진 중이다 (2027년 하반기 완공 목표로 보도됨).
- 오이도역(4호선·수인분당선)과 월곶역(수인분당선)이 배곧 인근 교통 거점이다.
- 대형마트와 영화관이 있는 중심상업지구가 배곧생명공원 인근에 있다.

### ❓ 확인이 필요한 것
- 해안 공원(배곧한울공원)의 정확한 위치와 규모
- 대학 캠퍼스가 배곧 안에서 정확히 어디에 있는지
- 오이도와 배곧의 정확한 위치 관계
- 배곧대교 부지에 실제로 공사 흔적(교각 등)이 있는지
- 소래철교로 실제 도보 통행이 가능한지

### 생활감 디테일 체크리스트
- [ ] 대단지 아파트와 넓고 텅 빈 왕복 도로
- [ ] 상가 건물마다 학원 간판 (교육도시 이미지)
- [ ] 상가 공실의 "임대" 현수막 (신도시의 현실)
- [ ] 바닷바람, 갯벌 냄새를 암시하는 텍스트, 갈매기 소리
- [ ] 바다 건너로 보이는 송도의 고층 빌딩 스카이라인
- [ ] 서울로 출퇴근하는 부모가 많다는 사실 (학원에 남겨진 아이들의 이유)
- [ ] 단지 내 경비실, 관리사무소 방송 스피커, 분리수거장
- [ ] 아파트 엘리베이터 안 게시판 (관리비 공지, 층간소음 안내문)
